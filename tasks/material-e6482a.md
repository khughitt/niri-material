Explore a keyboard-driven way to move windows between the active focus set and a backburner, and to expand a set into several workspaces. Consider paired/grouped windows moving as a unit and a shared material background, processing, glow, or ring. Current context: a terminal displaying dots' space-invaders art separates active windows above from backburner or independently running windows below; repeated manual movement creates friction. Preserve the goal of a smaller focus set and less context switching. These interaction and visual choices remain ideas, not an approved implementation.
