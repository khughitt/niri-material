# Native Materials v1 Parity Pass Implementation Plan

**Status:** approved/executing 2026-08-24; corrected to build and run both
renderer modes from the detached `v1-parity-old-surface` worktree.
Approved amendment 2026-08-25: preserved attempt evidence requires a fresh

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a complete, falsifiable 14-row semantic-response comparison
between native glass and the frozen Quickshell reference, then record whether
physical DRM acceptance may proceed.

**Architecture:** Run both implementations sequentially under the same pinned
old-surface niri binary on a 1280x720 headless Weston GL host. A POSIX-shell
replay fixture owns the processes, same-state config reloads, duplicate captures, and
artifact manifest; one dependency-free Node analyzer converts ImageMagick raw
RGB dumps into per-row response/noise metrics. Cross-renderer pixels are never
compared directly: each implementation must independently clear the same
directional oracle and its own measured noise floor.

**Tech Stack:** Rust/Cargo, niri 26.04, Weston 15 headless GL, Quickshell + Qt
Quick 3D, POSIX shell, Node.js built-ins and `node:test`, ImageMagick 7, `jq`,
kitty, and swaybg.

**Spec:** `docs/materials/2026-08-24-v1-parity-design.md`

  const mask = new Uint8Array(width * height);

- [ ] **Step 4: Implement deterministic grid registration and static metrics**

`estimateDisplacement` operates on linear RGB: sample 9x9 blocks on a 24 px
lattice inside the responsive mask. Accept a source block only when the
standard deviation of both its row-mean and column-mean luminance profiles is
at least `8/255`; overall block variance alone is insufficient because a
single vertical or horizontal line leaves one axis unobservable. Search
integer offsets in `[-64,64]` separately on those profiles, then score the
resulting `(dx, dy)` against the full 9x9 block. Break ties by the shortest
vector, then y, then x. Record the accepted-block count and reject an empty
field. If either winning component for any accepted block is exactly `-64` or
`64`, fail that row as a saturated estimate instead of reporting a capped
metric. This axis search is bounded and sufficient for the orthogonal
diagnostic grid; it avoids a quadratic 2-D brute-force search. The 200 px grid
period is greater than twice the search radius, so the nearest phase is
unambiguous.

Native static registration uses its source capture. Reference static
registration uses the capture itself as described in Task 1: for each sampled
rendered block, choose the nearest wholly unmasked block at an integer
multiple of 200 px in x and y. Reject candidates outside the preview or with
any masked pixel, and reject the sample if none remains. This is a source
provider difference only; the profile gates, search, scoring, saturation
check, and metrics remain identical.

Use the field as follows:

- `ior` and `thickness`: mean displacement magnitude must increase;
- `chromatic-aberration`: mean pairwise distance among independently fitted
  R/G/B vectors must increase;
- `distortion`: displacement-field variance must clear noise and remain
  inside the material mask;
- `distortion-scale`: `fieldFrequency`, the mean neighboring-vector delta
  divided by mean vector magnitude, must increase;
- `anisotropic-blur`: mean 10%-to-90% transition width across responsive grid
  edges must increase; and
- `samples`: RMS linear-luminance residual after a 3x3 box filter inside the
  responsive mask must decrease from the activated anisotropic state.

Attenuation uses linear RGB over a data-derived flat-face region: pixels at
least 16 px inside the responsive-mask boundary whose default displacement
magnitude does not exceed duplicate noise. Reject an empty region. This
excludes the 12 px default chamfer on both implementations without using
window bounds. For `attenuation-color`, red decreases, green increases, and
blue's maximum per-pixel delta must not exceed its duplicate-capture noise.
For shorter `attenuation-distance`, red and green decrease and blue stays at
its noise floor. `thickness` additionally requires red/green attenuation to
increase.

Every metric is computed for both duplicate cross-state pairings; the smaller
signal must strictly exceed the largest within-state duplicate result using
the same metric.

- [ ] **Step 5: Implement geometry and motion metrics**

`geometryMetrics` returns inclusive responsive-mask width/height and centroid.
Require `lip=24` to increase width and height; `shift-x=-6` to move the
centroid left with unchanged width/height; and `shift-y=-6` to move it up with
unchanged width/height. “Unchanged” means its duplicate-pair delta does not
exceed that row's measured geometry noise.

For each default/variant comparison, first reject missing or non-monotonic
actual offsets. `motionMetrics` registers each frame to its settled geometry
and returns
`{ series: [{ offsetMs, deformation, rippleRms }], settledChangedFraction }`.
`alignMotionSeries` takes scalar `{ offsetMs, value }` series, intersects their
actual-offset ranges, and returns `{ offsets, values }` after linearly
interpolating onto 10 ms offsets from
`ceil(max(first offsets) / 10) * 10` through `min(last offsets)`. It never
interpolates RGB data. Independently require every real burst to contain at
least three actual captures below 326 ms, one at or after 400 ms, and one at or
after 500 ms. Reject the case unless the common grid begins at or before the
implementation's measured `first_offset_budget_ms` and reaches 400 and 500 ms.

`summarizeMotion(defaultBursts, variantBursts)` calls `alignMotionSeries` for
both scalar metrics and is the sole producer of this aligned summary:

```js
{
  commonOffsets,
  default: [
    { peakDeformation, peakRippleRms, settledChangedFraction },
    { peakDeformation, peakRippleRms, settledChangedFraction }
  ],
  variant: [
    { peakDeformation, peakRippleRms, settledChangedFraction },
    { peakDeformation, peakRippleRms, settledChangedFraction }
  ]
}
```

`jelly-flex=0.02` must increase peak deformation. `jelly-ripple=0.5` must

its settled changed fraction must remain below 0.001. Compute every peak on
the common grid. Both duplicate variant curves must agree in direction; the
smaller default-to-variant aligned peak delta must exceed the largest
within-setting duplicate aligned peak spread.
