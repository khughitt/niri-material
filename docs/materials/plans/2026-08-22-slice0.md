# Native Materials Slice 0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove the native-material renderer seam in a niri fork: a persistent
window-texture shader with a background sampler on one hard-coded test window,
under continuous redraw, surviving move/resize/open-close/overview with zero
steady-state texture allocation.

**Architecture:** A retained `MaterialState` on `Tile` (offscreen buffer +
stable element identity, no texture clones) produces a transient
`MaterialRenderElement` each frame. The element resolves the background
texture at **draw time** (`EffectBuffer::render` requires a `GlesFrame`, so
collection-time resolution is impossible) and delegates GL drawing to a
`ShaderRenderElement` constructed inside `draw()`. The window body renders
into the material offscreen at collection time; during resize the
`ResizeRenderElement` renders into it instead.

**Tech Stack:** Rust, niri v26.04 (Smithay 0.7.0 rev `ff5fa7df`), GLES2 GLSL
(`#version 100` implied by the shader wrapper).

**Spec:** `docs/materials/2026-08-22-v1-design.md`
This plan implements **§5 slice 0 only**.

- [ ] **Step 1: Write the shader**

Create `src/render_helpers/shaders/material.frag`:
```glsl
precision highp float;

varying vec2 niri_v_coords;
uniform vec2 niri_size;
uniform float niri_scale;
uniform float niri_alpha;

uniform sampler2D niri_tex_win;
uniform sampler2D niri_tex_bg;
uniform vec4 mat_win_rect;
uniform vec4 mat_bg_rect;
uniform float mat_time;

void main() {
    vec2 win_uv = mat_win_rect.xy + niri_v_coords * mat_win_rect.zw;
    vec4 win = texture2D(niri_tex_win, win_uv);

    vec2 bg_uv = mat_bg_rect.xy + niri_v_coords * mat_bg_rect.zw;
    // Tiny time-driven refraction wobble: proves continuous redraw
    // visually without obscuring content.
    bg_uv += 0.002 * vec2(sin(mat_time + niri_v_coords.y * 24.0),
                          cos(mat_time * 0.9 + niri_v_coords.x * 24.0));
    vec3 bg = texture2D(niri_tex_bg, clamp(bg_uv, 0.0, 1.0)).rgb;

    // Stand-in for the glass terms: a cool tint. Premultiplied, slab
    // coverage = 1.0 (element area == window area in slice 0).
    vec3 glassed = bg * vec3(0.86, 0.90, 1.0);

    vec4 color = vec4(win.rgb + (1.0 - win.a) * glassed,
                      win.a + (1.0 - win.a) * 1.0);
    gl_FragColor = color * niri_alpha;
}
```
Note: if Task 6 shows the window vertically flipped, flip the y term:
`win_uv.y = mat_win_rect.y + (1.0 - niri_v_coords.y) * mat_win_rect.w` —
offscreen texture orientation is one of the things slice 0 exists to
discover.

- [ ] **Step 5: Write `MaterialState` and `MaterialRenderElement`**

Same file. Retained state holds **no textures and no buffer references**
(spec §2); the transient element holds the frame's clones and the buffer
`Rc`, and dies with the frame's element list.

```rust
use std::cell::{Cell, RefCell};
use std::collections::HashMap;
use std::rc::Rc;
use std::time::Duration;

#[derive(Debug)]
pub struct MaterialState {
    pub offscreen: OffscreenBuffer,
    id: Id,
    // Cell: elements are produced from `Tile::render_inner(&self)`.
    commit: Cell<CommitCounter>,
}

impl MaterialState {
    pub fn new() -> Self {
        Self {
            offscreen: OffscreenBuffer::default(),
            id: Id::new(),
            commit: Cell::new(CommitCounter::default()),
        }
    }

    pub fn has_program(renderer: &mut GlesRenderer) -> bool {
        Shaders::get(renderer).material.is_some()
    }

    #[allow(clippy::too_many_arguments)]
    pub fn element(
        &self,
        area: Rectangle<f64, Logical>,
        scale: f64,
        alpha: f32,
        time: Duration,
        win_rect: [f32; 4],
        win_src: Rectangle<f64, Buffer>,
        bg_rect: [f32; 4],
        win_texture: GlesTexture,
        bg: Rc<RefCell<EffectBuffer>>,
    ) -> MaterialRenderElement {
        // Slice 0: continuous redraw — full damage every frame.
        let mut commit = self.commit.get();
        commit.increment();
        self.commit.set(commit);
        MaterialRenderElement {
            id: self.id.clone(),
            commit,
            area,
            scale,
            alpha,
            time,
            win_rect,
            win_src,
            bg_rect,
            win_texture,
            bg,
        }
    }
}

#[derive(Debug)]
pub struct MaterialRenderElement {
    id: Id,
    commit: CommitCounter,
    area: Rectangle<f64, Logical>,
    scale: f64,
    alpha: f32,
    time: Duration,
    /// Window sub-rect of the offscreen texture, normalized UV
    /// (`mat_win_rect`) — the buffer may be larger than the window.
    win_rect: [f32; 4],
    /// The same sub-rect in buffer pixels, for the plain-draw fallback.
    win_src: Rectangle<f64, Buffer>,
    bg_rect: [f32; 4],
    win_texture: GlesTexture,
    bg: Rc<RefCell<EffectBuffer>>,
}
```
Mirror the exact import paths and the `Shaders::get`/`has_shader` idiom from
`ResizeRenderElement` (`src/render_helpers/resize.rs`) — that file is the

- [ ] **Step 7: Implement `RenderElement` — draw-time texture resolution**

The core of the architecture: resolve the background texture inside
`draw()`, then delegate to a **transiently constructed**
`ShaderRenderElement` (its `draw` uses the passed `dst`, not its own area —
shader_element.rs:366-374 — so a throwaway instance is safe).

```rust
impl RenderElement<GlesRenderer> for MaterialRenderElement {
    fn draw(
        &self,
        frame: &mut GlesFrame<'_, '_>,
        src: Rectangle<f64, Buffer>,
        dst: Rectangle<i32, Physical>,
        damage: &[Rectangle<i32, Physical>],
        opaque_regions: &[Rectangle<i32, Physical>],
        cache: Option<&UserDataMap>,
    ) -> Result<(), GlesError> {
        let bg_texture = match self.bg.borrow_mut().render(frame, false) {
            Ok(tex) => Some(tex),
            Err(err) => {
                warn!("material: error rendering background buffer: {err:?}");
                None
            }
        };

        let Some(bg_texture) = bg_texture else {
            // This element is the only presented window element — never
            // skip drawing, or the window disappears. Fall back to the
            // window texture, drawn plainly.
            return frame.render_texture_from_to(
                &self.win_texture,
                self.win_src,
                dst,
                damage,
                opaque_regions,
                Transform::Normal,
                self.alpha,
                None,
                &[],
            );
        };

        let uniforms: Rc<[Uniform<'static>]> = Rc::new([
            Uniform::new("mat_time", self.time.as_secs_f32()),
            Uniform::new("mat_win_rect", self.win_rect),
            Uniform::new("mat_bg_rect", self.bg_rect),
        ]);
        let textures = HashMap::from([
            (String::from("niri_tex_win"), self.win_texture.clone()),
            (String::from("niri_tex_bg"), bg_texture),
        ]);
        let inner = ShaderRenderElement::new(
            ProgramType::Material,
            self.area.size,
            None,
            self.scale as f32,
            self.alpha,
            uniforms,
            textures,
            Kind::Unspecified,
        );
        RenderElement::<GlesRenderer>::draw(&inner, frame, src, dst, damage, opaque_regions, cache)
    }

    fn underlying_storage(&self, _renderer: &mut GlesRenderer) -> Option<UnderlyingStorage<'_>> {
        None // no direct scanout for material windows (spec §2)
    }
}

impl<'render> RenderElement<TtyRenderer<'render>> for MaterialRenderElement {
    fn draw(
        &self,
        frame: &mut TtyFrame<'_, '_, '_>,
        src: Rectangle<f64, Buffer>,
        dst: Rectangle<i32, Physical>,
        damage: &[Rectangle<i32, Physical>],
        opaque_regions: &[Rectangle<i32, Physical>],
        cache: Option<&UserDataMap>,
    ) -> Result<(), TtyRendererError<'render>> {
        let frame = frame.as_gles_frame();
        RenderElement::<GlesRenderer>::draw(self, frame, src, dst, damage, opaque_regions, cache)?;
        Ok(())
    }

    fn underlying_storage(
        &self,
        _renderer: &mut TtyRenderer<'render>,
    ) -> Option<UnderlyingStorage<'_>> {
        None
    }
}
```
The `draw` signatures (including `cache: Option<&UserDataMap>`) and the TTY
impl are copied from `ShaderRenderElement` (shader_element.rs:289-296,
517-549); the `render_texture_from_to` call is exact, and `[f32; 4]`
implements `Into<UniformValue>`, so `Uniform::new` accepts it as written.

```rust
let mut pushed_material = false;

    let material = self.material.as_ref().unwrap();
    let mut gles_ctx = ctx.as_gles();

    if MaterialState::has_program(gles_ctx.renderer) {
        // Window body at (0, 0), alpha 1.0 (spec §2: window-rule opacity
        // applies exactly once, on the material element below).
        let mut window_elements = Vec::new();

            .render_normal(gles_ctx.r(), Point::from((0., 0.)), scale, 1., &mut |elem| {
                window_elements.push(elem)

        // material this frame rather than sampling garbage.

                    let win_src = offscreen_elem.src();
                    let tex_size = win_texture.size().to_f64();

                        (win_src.loc.x / tex_size.w) as f32,
                        (win_src.loc.y / tex_size.h) as f32,
                        (win_src.size.w / tex_size.w) as f32,
                        (win_src.size.h / tex_size.h) as f32,
                    ];

                    // xray_pos already corresponds to the window position
                    // (it includes window_loc); add only the
                    // offscreen-relative offset. Zoom handling mirrors
                    // xray.rs:110.
                    let bg_size = bg.borrow().logical_size();
                    let geo_in_backdrop = Rectangle::new(
                        (xray_pos.pos_in_backdrop + offscreen_geo.loc)
                            .upscale(xray_pos.zoom),
                        area.size.upscale(xray_pos.zoom),
                    );
                    let bg_rect = bg_uv_rect(geo_in_backdrop, bg_size);

                    let elem = material.element(
                        area, self.scale, win_alpha, clock_time, win_rect,
                        win_src, bg_rect, win_texture, bg,
                    );

                    // Presentation/frame-callback tracking must find the
                    // element actually present in the output — rewrite the
                    // offscreen data id to the material element, exactly
                    // like the resize path does (tile.rs:1141-1146).
                    data.id = elem.id().clone();
                    self.window.set_offscreen_data(Some(data));

                    push(elem.into());
                    pushed_material = true;
                }
                Err(err) => {
                    warn!("material: error rendering window to offscreen: {err:?}");
                }
            }
        }
    }
}
if !pushed_material {
    // stock path, unchanged: rounded-corner damage push (:1230-1233) +
    // render_normal with the clip closure (:1235-1238)
}
```
Notes for the implementer:
- `render_inner` is `&self`, so `self.material.as_ref()`, `self.window`, and
  `material.offscreen.render(&self, ...)` are all shared borrows —
  `MaterialState` was designed for this (`element(&self)` via `Cell`).
- `clock_time`: use the same clock call the `baba_is_float` offset uses
  (tile.rs:1015-1019) — match it exactly, do not introduce a new time
  source.
- `elem.id()` is `Element::id` — the trait is already in scope in tile.rs
  (the resize path calls `elem.id()` at :1142).
- Rounded-corner clipping (`ClippedSurfaceRenderElement`) is skipped for
  material windows in slice 0 — record as a deviation in Task 7.

- [ ] **Step 5: Render integration — resize path**

In the resize branch, the stock success path (:1141-1148) is:
```rust
data.id = elem.id().clone();
self.window.set_offscreen_data(Some(data));
push(elem.into());
pushed_resize = true;
```
For material windows, wrap that tail: render `elem` (the
`ResizeRenderElement`, which implements `RenderElement<GlesRenderer>` — all
`OffscreenBuffer::render` requires) into the material offscreen and present
the material element instead. `data` here is the resize offscreen's
`OffscreenData` carrying the window surfaces' render states — it, not the
material offscreen's data, is what presentation tracking needs; merge and
rewrite:

```rust
let mut done = false;
if material_ready {
    let material = self.material.as_ref().unwrap();
    let xray = ctx.xray.unwrap();
    let bg = xray.background[ctx.target as usize].clone();
    if MaterialState::has_program(ctx.renderer)
        && bg.borrow_mut().prepare(ctx.renderer, false)
    {
        // The stock element retains win_alpha for the fallback below; only
        // the copy rendered into the material offscreen uses alpha 1.0.
        let material_elem = elem.clone().with_alpha(1.);
        match material.offscreen.render(
            ctx.renderer,
            scale,
            std::slice::from_ref(&material_elem),
        ) {
            Ok((offscreen_elem, _sync, mat_data)) => {
                let offscreen_geo =
                    offscreen_elem.geometry(scale).to_f64().to_logical(scale);
                // The resize element's coordinates are anchored at the
                // window position: `area` is constructed as
                // `Rectangle::new(window_render_loc, animated_window_size)`
                // (tile.rs:1064), so the window-relative offset is
                // offscreen_geo.loc minus window_render_loc — verified.
                let rel = offscreen_geo.loc - window_render_loc;
                let area = Rectangle::new(offscreen_geo.loc, offscreen_geo.size);

                let win_texture = offscreen_elem.texture().clone();
                let win_src = offscreen_elem.src();
                let tex_size = win_texture.size().to_f64();
                let win_rect = [
                    (win_src.loc.x / tex_size.w) as f32,
                    (win_src.loc.y / tex_size.h) as f32,
                    (win_src.size.w / tex_size.w) as f32,
                    (win_src.size.h / tex_size.h) as f32,
                ];

                let bg_size = bg.borrow().logical_size();
                let geo_in_backdrop = Rectangle::new(
                    (xray_pos.pos_in_backdrop + rel).upscale(xray_pos.zoom),
                    area.size.upscale(xray_pos.zoom),
                );
                let bg_rect = bg_uv_rect(geo_in_backdrop, bg_size);

                // Window-rule opacity applies exactly once, after the
                // alpha-1 resize result is material-composited.
                let mat_elem = material.element(
                    area, self.scale, win_alpha, clock_time, win_rect, win_src,
                    bg_rect, win_texture, bg,
                );

                // Merge both offscreen layers' states; the presented id is
                // the material element's.
                data.id = mat_elem.id().clone();
                data.states.states.extend(mat_data.states.states);
                self.window.set_offscreen_data(Some(data));

                push(mat_elem.into());
                pushed_resize = true;
                done = true;
            }
            Err(err) => {
                warn!("material: error rendering resize element to offscreen: {err:?}");
            }
        }
    }
}
if !done {
    // Stock tail, verbatim (:1141-1148): `elem` still carries win_alpha,
    // so the plain resize fallback applies opacity exactly once.
}
```
(`RenderElementStates::states` is public; the merge compiles as written.)
