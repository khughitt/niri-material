# Ring beam implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Status:** draft, 2026-09-19; awaiting review before execution.

**Goal:** Replace the focus sweep's interference pattern with a comet of light travelling once around the inside of the glass face at a constant px/s pace, a gap in from the face edge, then a quiet resting glow — with `ring-beam-speed`, `ring-gap` and `ring-glow` in niri and Prism.

**Architecture:** `niri-config` gains the three keys and rejects the two retired ones by name. A new `src/render_helpers/material/ring.rs` holds the beam's pure geometry and envelope (face box, fitted radii, perimeter, tail length, per-frame `head`/`env`/`decay`, and an `f32` twin of the shader's comet) so the constants are tested where they are defined. The tile's `FocusSweep` becomes `FocusBeam { started, speed, run_px }`; `material_dynamics` (which already has window size, chamfer and jelly) computes the perimeter each rendered frame, writes the run length back, and fills the beam inputs. The shader stores the inner face in globals, gains `arcPosition`, measures the band from the face edge, and draws the comet plus an edge spill. Prism replaces `sweepMs` with `beamSpeed` and adds `gap` and `glow`.

**Tech Stack:** Rust (smithay/niri, knuffel KDL), GLSL ES (`main.frag`, `prelude.frag`), Bash smoke fixtures under `docs/materials/scripts`, Prism (Node 20, `node:test`, `yaml`).

**Spec:** `docs/specs/2026-09-19-ring-beam-design.md` (this worktree). Read its §1–§3 before Tasks 1–3 and §4 before Task 5. The pipeline every task assumes is `docs/materials/render-pipeline.md`.

**Task:** `material-2c3984` under `material-a76720`. Step children are created per task heading below (`tasks add … --parent material-2c3984 --plan docs/plans/2026-09-19-ring-beam.md --step "<heading>"`).

- Keys and values verbatim from spec §3: `ring-beam-speed` float px/s default `300` range 0–5000; `ring-gap` float px default `8` range 0–128; `ring-glow` float default `1.0` range 0–3; `ring-width` unchanged (2.6, positive). `ring-sweep-ms` → `ring-sweep-ms was replaced by ring-beam-speed; see material-config.md`; `ring-inset` → `ring-inset was replaced by ring-gap; see material-config.md`; the existing `ring-drift-hz` rejection now names `ring-beam-speed`.

They live once in `ring.rs` and once, with the same names, at the top of the shader's ring block; a test in Task 3 greps the shader for each value.
- Formulas verbatim from spec §1.3 and §2: `dHead = |mod(head − s + P/2, P) − P/2|`; the **entire** tail expression inside `0 < behind < L`; `beam = BASE · glow · (decay · (head + tail) + REST)`; `env` exactly `0` for `t ≥ P/speed`; rest is `head = 0, env = 0, decay = 0`.
- The tile snapshots only `started` and `speed`; `P` and `L` come from the effective face (jelly included) of the latest rendered frame.
- Uniforms: `mat_sig_focus` becomes `vec4(focus, head, env, decay)` registered `_4f`; `mat_sig_ring` becomes `vec3(gap, width, glow)` registered `_3f`.
- Repository protocol: `tasks start <child>` before each task, `tasks done <child> "<result>"` in its commit, `tasks check` before every commit; `cargo fmt --all` then `just test` and `just check` before every commit; every commit that adds or removes files runs `python3 tools/upstream-report` and stages `docs/materials/upstream-divergence.md`; conventional commits, no attribution trailers; live nested-niri runs only on headless weston units. //! (docs/specs/2026-09-19-ring-beam-design.md §1–§2). Pure: the tile asks
//! this for the perimeter and the frame values, the shader mirrors `comet`.

#[cfg(test)]
mod tests {

    use std::time::Duration;

    use super::*;

    const HALF: f64 = 2. - FRAC_PI_2;

    fn plain(w: f64, h: f64, r: f64) -> Face {
        Face { half: [w / 2., h / 2.], radii: [r; 4] }
    }

    #[test]
    fn perimeter_of_a_rounded_box_and_its_degenerate_cases() {
        let f = plain(200., 100., 10.);
        assert!((beam_perimeter(&f, 0.) - (4. * 150. - HALF * 40.)).abs() < 1e-9);
        assert!((beam_perimeter(&plain(200., 100., 0.), 0.) - 600.).abs() < 1e-9);
        // a gap larger than the radius floors the radius at 0: the line is a plain box
        assert!((beam_perimeter(&plain(200., 100., 10.), 12.) - (4. * (88. + 38.))).abs() < 1e-9);
        // a face narrower than 2·gap has no beam line
        assert_eq!(beam_perimeter(&plain(200., 14., 8.), 8.), 0.);
        assert_eq!(beam_perimeter(&plain(200., 16., 8.), 8.), 0.);

    fn the_face_mirrors_slab_surface_with_and_without_jelly() {
        // 100×100 window, bevel 12, offset 6: slab 112, inner face 88 (prelude.frag comment)
        let f = face([100., 100.], 12., [6., 6.], 12., [8.; 4], [0., 0.]);
        assert_eq!(f.half, [44., 44.]);
        assert_eq!(f.radii, [8.; 4]);
        // jelly resize +8 on x: inner_half.x · (1 + 8 / 112)
        let j = face([100., 100.], 12., [6., 6.], 12., [8.; 4], [8., 0.]);
        assert!((j.half[0] - 44. * (1. + 8. / 112.)).abs() < 1e-9);
        assert_eq!(j.half[1], 44.);
        // radii are fitted against min(inner_half, half_ext − chamfer), never past it
        let big = face([40., 40.], 12., [6., 6.], 12., [30.; 4], [0., 0.]);
        assert!(big.radii.iter().all(|r| (*r - 14.).abs() < 1e-9), "{:?}", big.radii);
    }

    fn arc_position_walks_clockwise_from_the_top_left_arc() {
        let f = plain(200., 100., 10.);
        let gap = 0.;
        let p = beam_perimeter(&f, gap);
        let top = 200. - 20.;
        let right = 100. - 20.;
        // start of the top edge, its middle, its end
        assert!((arc_position(&f, gap, [-90., -50.]) - 0.).abs() < 1e-9);
        assert!((arc_position(&f, gap, [0., -50.]) - 90.).abs() < 1e-9);
        assert!((arc_position(&f, gap, [90., -50.]) - top).abs() < 1e-9);

        let q = [c[0] + 10. * a.cos(), c[1] + 10. * a.sin()];
        assert!((arc_position(&f, gap, q) - (top + 10. * FRAC_PI_2 / 2.)).abs() < 1e-6);

        assert_eq!(tail_length(6000.), 1200.);

        let p = 3000.;

        let at = |ms: u64| beam_frame(Duration::from_millis(ms), v, p, Envelope::Plateau);
        assert_eq!(at(0).head, 0.);
        assert_eq!(at(0).env, 0.);

        assert_eq!(at(10_000).env, 0., "the head still ends its lap at the seam");
        assert!(at(10_000).decay > 0., "while the tail is still draining");
        let end = Duration::from_secs_f64(run);
        assert!(beam_frame(end, v, p, Envelope::Splash).decay.abs() < 1e-6);
    }

    #[test]
    fn comet_is_symmetric_across_the_seam_and_tapers_to_zero() {
        let p = 4000.;
        let glow = 1.;
        let rest = BEAM_BASE * BEAM_REST;
        let launch = BeamFrame { head: 20., env: 1., decay: 1. };
        let at = |s: f32, f: BeamFrame| (comet(s, f, p, glow) - rest) / BEAM_BASE;
        assert!((at(0., launch) - 0.607).abs() < 1e-3, "{}", at(0., launch));
        assert!((at(p - 20., launch) - 0.135).abs() < 1e-3, "across the seam");
        let back = BeamFrame { head: p - 20., env: 1., decay: 1. };
        assert!((at(20., back) - 0.135).abs() < 1e-3, "on the return");

        assert_eq!(at(2000., mid), 0., "no tail at behind = 0");
        assert!(at(2000. - 300., mid) > 0.1);
        assert_eq!(at(2000. - l, mid), 0., "zero at L");
        assert!(at(2000. - l + 1., mid) < 1e-5, "and flat there");
        assert_eq!(at(2000. + 10., mid), 0., "nothing ahead of the head");
    }

    #[test]
    fn rest_is_finite_in_f32_everywhere() {
        let p = 4000.;
        for s in [0., 1., 2000., p - 1., p] {
            let v = comet(s, BeamFrame::REST, p, 1.);
            assert!(v.is_finite(), "s = {s}: {v}");
            assert!((v - BEAM_BASE * BEAM_REST).abs() < 1e-6, "s = {s}: {v}");

        // a head past the seam with decay still up contributes only its tail

        assert!((comet(50., drain, p, 1.) - BEAM_BASE * BEAM_REST).abs() < 1e-6, "no head at s = 50");
        assert!(comet(p - 50., drain, p, 1.) > BEAM_BASE * BEAM_REST, "tail at s = P − 50");
    }

    fn glow_scales_the_whole_focus_light() {
        let f = BeamFrame { head: 100., env: 1., decay: 1. };

        assert!((comet(3000., BeamFrame::REST, 4000., 0.5) - 0.5 * BEAM_BASE * BEAM_REST).abs() < 1e-7);
    }
}

use std::f64::consts::{FRAC_PI_2, PI};
use std::time::Duration;

/// Gaussian half-width of the head, px.
pub const BEAM_HEAD_SIGMA: f32 = 20.;
/// Tail brightness just behind the head.
pub const BEAM_TAIL_START: f32 = 0.6;
/// Tail length as a fraction of the perimeter, and its cap in px.
pub const BEAM_TAIL_FRACTION: f64 = 0.25;
pub const BEAM_TAIL_MAX: f64 = 1200.;
/// Resting glow once the beam has passed.
pub const BEAM_REST: f32 = 0.2;
/// Edge spill onto the chamfer.
pub const BEAM_SPILL: f32 = 0.25;
/// Focus light scale (the sweep's 0.7).
pub const BEAM_BASE: f32 = 0.7;
/// Head fade in and out.
pub const BEAM_FADE: Duration = Duration::from_millis(300);
/// The splash envelope's shorter fade-in.
pub const BEAM_SPLASH_FADE: Duration = Duration::from_millis(100);
/// The envelope shape that ships; the other is kept for the sheets.
pub const BEAM_ENVELOPE: Envelope = Envelope::Plateau;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Envelope {
    /// Full brightness from fade-in to fade-out.
    Plateau,
    /// Brightest at launch, decaying over the run like a ripple.
    Splash,
}

/// The face the shader draws, jelly included: half extents and fitted radii
/// (top-left, top-right, bottom-right, bottom-left), centred at the origin.
#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Face {
    pub half: [f64; 2],
    pub radii: [f64; 4],
}

/// Mirrors `fitRadii` in prelude.frag: scale all four radii by one factor
/// so no adjacent pair exceeds its edge.
pub fn fit_radii(r: [f64; 4], half: [f64; 2]) -> [f64; 4] {
    let edge = [2. * half[0], 2. * half[1]];
    let k = (edge[0] / (r[0] + r[1]).max(1e-6))
        .min(edge[0] / (r[3] + r[2]).max(1e-6))
        .min(edge[1] / (r[0] + r[3]).max(1e-6))
        .min(edge[1] / (r[1] + r[2]).max(1e-6))
        .min(1.);
    r.map(|x| x * k)
}

/// Mirrors `material_frame` and `slabSurface`: the slab is the window
/// inflated by `bevel − max|offset|`, the face is the slab minus the chamfer,
/// scaled by the jelly resize; radii are fitted against whichever box binds
/// harder. Pixel alignment (`ceil`/`round` to the scale) is ignored: it moves
/// the perimeter by under a pixel.
pub fn face(
    window_size: [f64; 2],
    bevel: f64,
    offset: [f64; 2],
    chamfer: f64,
    corner_radius: [f64; 4],
    jelly_resize: [f64; 2],
) -> Face {
    let inflate = bevel - offset[0].abs().max(offset[1].abs());
    let half_ext = [window_size[0] / 2. + inflate, window_size[1] / 2. + inflate];
    let inner = [half_ext[0] - chamfer, half_ext[1] - chamfer];
    let half = [
        inner[0] * (1. + jelly_resize[0] / (2. * half_ext[0]).max(1.)),
        inner[1] * (1. + jelly_resize[1] / (2. * half_ext[1]).max(1.)),
    ];
    let radius_half = [half[0].min(inner[0]), half[1].min(inner[1])];
    Face {
        half,
        radii: fit_radii(corner_radius, radius_half),
    }
}

fn beam_line(face: &Face, gap: f64) -> Option<([f64; 2], [f64; 4])> {
    let half = [face.half[0] - gap, face.half[1] - gap];
    if half[0] <= 0. || half[1] <= 0. {
        return None;
    }
    Some((half, face.radii.map(|r| (r - gap).max(0.))))
}

/// Perimeter of the beam line; 0 when the face is too small to hold one.
pub fn beam_perimeter(face: &Face, gap: f64) -> f64 {
    let Some((half, r)) = beam_line(face, gap) else {
        return 0.;
    };
    4. * (half[0] + half[1]) - (2. - FRAC_PI_2) * r.iter().sum::<f64>()
}

pub fn tail_length(perimeter: f64) -> f64 {
    (perimeter * BEAM_TAIL_FRACTION).min(BEAM_TAIL_MAX)
}

/// Distance along the beam line of the point nearest `q` (relative to the
/// face centre, y down), clockwise from the end of the top-left arc.
/// Mirrors `arcPosition` in prelude.frag; a projection, valid for any `q`.
pub fn arc_position(face: &Face, gap: f64, q: [f64; 2]) -> f64 {
    let Some((h, r)) = beam_line(face, gap) else {
        return 0.;
    };
    let [tl, tr, br, bl] = r;
    let top = 2. * h[0] - tl - tr;
    let right = 2. * h[1] - tr - br;
    let bottom = 2. * h[0] - br - bl;
    let left = 2. * h[1] - bl - tl;
    let after_top = top + tr * FRAC_PI_2;
    let after_right = after_top + right + br * FRAC_PI_2;
    let after_bottom = after_right + bottom + bl * FRAC_PI_2;
    let (x, y) = (q[0], q[1]);
    if x > h[0] - tr && y < -h[1] + tr {
        let a = (y + h[1] - tr).atan2(x - h[0] + tr).clamp(-FRAC_PI_2, 0.);
        return top + tr * (a + FRAC_PI_2);
    }
    if x > h[0] - br && y > h[1] - br {
        let a = (y - h[1] + br).atan2(x - h[0] + br).clamp(0., FRAC_PI_2);
        return after_top + right + br * a;
    }
    if x < -h[0] + bl && y > h[1] - bl {
        let a = (y - h[1] + bl).atan2(x + h[0] - bl).clamp(FRAC_PI_2, PI);
        return after_right + bottom + bl * (a - FRAC_PI_2);
    }
    if x < -h[0] + tl && y < -h[1] + tl {
        let mut a = (y + h[1] - tl).atan2(x + h[0] - tl);
        if a > 0. {
            a -= 2. * PI;
        }
        let a = a.clamp(-PI, -FRAC_PI_2);
        return after_bottom + left + tl * (a + PI);
    }
    let to_edge = [h[0] - x.abs(), h[1] - y.abs()];
    if to_edge[1] <= to_edge[0] {
        if y < 0. {
            return (x + h[0] - tl).clamp(0., top);
        }
        return after_right + (h[0] - br - x).clamp(0., bottom);
    }
    if x > 0. {
        return after_top + (y + h[1] - tr).clamp(0., right);
    }
    after_bottom + (h[1] - tl - y).clamp(0., left)
}

/// What the shader needs for one frame.
#[derive(Debug, Clone, Copy, PartialEq)]
pub struct BeamFrame {
    /// Head arc position, px; unbounded during a run.
    pub head: f32,
    /// Head cutoff, 0–1; exactly 0 once the head has completed its lap.
    pub env: f32,
    /// Shared brightness of head and tail, 0–1.
    pub decay: f32,
}

impl BeamFrame {
    /// The resting state (spec §1.3): no head, no tail, only the glow.
    pub const REST: Self = Self { head: 0., env: 0., decay: 0. };
}

fn smoothstep(e0: f64, e1: f64, x: f64) -> f64 {
    if e1 <= e0 {
        return if x >= e1 { 1. } else { 0. };
    }
    let t = ((x - e0) / (e1 - e0)).clamp(0., 1.);
    t * t * (3. - 2. * t)
}

/// The frame values at `elapsed` for a beam of `speed` on a `perimeter`.
/// `env` is exactly zero from the lap's end on, whatever the envelope does.
pub fn beam_frame(elapsed: Duration, speed: f64, perimeter: f64, envelope: Envelope) -> BeamFrame {
    let t = elapsed.as_secs_f64();
    let lap = perimeter / speed;
    let run = (perimeter + tail_length(perimeter)) / speed;
    let fade_in = match envelope {
        Envelope::Plateau => BEAM_FADE,
        Envelope::Splash => BEAM_SPLASH_FADE,
    }
    .as_secs_f64();
    let fade = BEAM_FADE.as_secs_f64();
    let env = if t >= lap {
        0.
    } else {
        smoothstep(0., fade_in, t) * (1. - smoothstep(lap - fade, lap, t))
    };
    let decay = match envelope {
        Envelope::Plateau => 1.,
        Envelope::Splash => {
            let x = (1. - t / run).clamp(0., 1.);
            x * x
        }
    };
    BeamFrame {
        head: (speed * t) as f32,
        env: env as f32,
        decay: decay as f32,
    }
}

/// The focus light at arc position `s`: the shader's formula in `f32`, so
/// its constants are tested here. Mirrors the ring block of main.frag.
pub fn comet(s: f32, frame: BeamFrame, perimeter: f32, glow: f32) -> f32 {
    let sigma = BEAM_HEAD_SIGMA;
    let l = tail_length(f64::from(perimeter)) as f32;
    let d = (frame.head - s + perimeter / 2.).rem_euclid(perimeter) - perimeter / 2.;
    let head = frame.env * (-d * d / (2. * sigma * sigma)).exp();
    let behind = frame.head - s;
    let tail = if behind > 0. && behind < l {
        let taper = 1. - behind / l;
        BEAM_TAIL_START * (-behind / l).exp() * (1. - (-behind / sigma).exp()) * taper * taper
    } else {
        0.
    };
    BEAM_BASE * glow * (frame.decay * (head + tail) + BEAM_REST)
}

// the face edge around `gap`, plus a soft halo bleeding into the glass. The
// caller caps the shared part of the light shift at half the gap before
// landing here, so dense glass cannot carry the core out past the face.
float filamentBand(vec2 q, float gap, float width, float scatter) {
    float d = -sdRoundedBox(q - g_face_center, g_face_half, g_face_r);
    float coreWidth = width + 6.0 * scatter;
